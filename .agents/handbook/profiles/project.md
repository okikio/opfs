For each selected dependency or provider, record why the project needs it, the relevant current contract and the consumer that proves it works. Provider-specific setup belongs in the project's own instructions, with current primary-source links and verified commands.

Review this profile when a supported host, dependency, data contract or delivery promise changes. Update affected consumers and checks together. An old successful run can remain evidence for its recorded conditions without proving the new configuration.
