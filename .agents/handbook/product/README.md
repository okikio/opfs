# Connect product questions to engineering work

The [shared product guide](../../guides/product/README.md) owns the method: identify the consequential question, run a relevant early probe and turn the observation into a decision. This chapter connects that method to project procedures and records.

Skills: `plan-changes`, `explore-ecosystems`, `benchmark-code`, `verify-behavior`, `write-docs`, `review-code`.

| Need | Owner |
| --- | --- |
| Find unknowns and decide what to ask | [Questions](../../guides/product/questions.md) |
| Design a small direct probe | [Experiments](../../guides/product/experiments.md) |
| Make a valid measurement | [Metrics](../../guides/product/metrics.md) |
| Report a dated observation and next decision | [Anchors](../../guides/product/anchors.md) |
| Turn evidence into executable work | [Planning](../../guides/product/planning.md) |
| Carry the method through a complete task | [Worked journey](journey.md), [playbook](../playbook.md) |

Use an existing task record for the brief, plan and observations. The shared guide's templates are prompts for useful information. They do not require a new tracking system or a record for every trivial action.
