# Record a service check

Make a record for each material contract, environment and consumer identity. Reuse it while its relevant inputs remain valid.

| Field | Value |
| --- | --- |
| Required user action and consuming process | |
| Service, endpoint role and contract version | |
| Environment, network location and principal reference | |
| Client, source and configuration identity | |
| Required operation and expected result | |
| Refusal or recovery case, if relevant | |
| Observation time and non-secret evidence | |
| Result: passed, failed, blocked, not run or not required | |
| Conditions that invalidate the result | |
| Cleanup, retention and owner | |
| Next action and unresolved limit | |

Record credential roles or versions, not values or low-entropy secret hashes. Separate credential existence, retrieval, use by the intended job and acceptance by the destination. Keep direct-probe and integrated application evidence distinct.
