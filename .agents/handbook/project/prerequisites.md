# Report the missing result and its owner

Report a known prerequisite when it affects the next work. Name the result needed and the check that will confirm it. Do not wait for unrelated research to finish.

| Missing result | Evidence and current status | Owner or authorized route | Concrete action | Verification | Independent work that can continue |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

For a package, name its intended version, export, registry and consumer. For a service, name the environment, identity role and required capability. For a native build, name the source, toolchain restriction, expected artifact and consumer check.

Distinguish absent configuration, inaccessible configuration, insufficient scope, expired identity, unsupported runtime and network failure. Keep unknowns explicit. Request an additional human decision only when it materially changes authority, scope or the intended tradeoff and cannot be resolved from available context.

Do not put secret values in this record. Preserve authorization already supplied for the same action and destination.
