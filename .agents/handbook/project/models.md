# Record model and runner choices

Use this record only when model calls or agent execution affect the intended outcome. Bind the choice to the actual consumer and representative work.

| Field | Value |
| --- | --- |
| User task and acceptance criteria | |
| Model/provider or runner identity | |
| Client, protocol, runtime and supported features | |
| Data, tools, credentials and allowed effects | |
| Limits, cancellation, retries and cleanup | |
| Representative inputs and independent quality checks | |
| Actual output, errors, retries, usage and latency | |
| Verified price basis, when currency cost is reported | |
| Job claims, result authority and artifact custody, when applicable | |
| Observed result, limits and next decision | |

Keep model response quality separate from the runner's execution and recovery behavior. A finite model probe cannot prove a whole application's tool loop or job isolation. Preserve failed attempts and assess useful completed tasks rather than comparing a price label alone.
