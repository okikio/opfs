# Maintain one active task record

Keep the latest outcome and next action easy to find. Update the record when intent, evidence, authorization, source or running operations change.

Use this shape when the task needs it:

```text
Outcome and intended user:
Latest accepted decisions and constraints:
Current source, branch, revision and local changes:
Applicable instructions and selected capabilities:
Consequential questions and current evidence:
Next decision and smallest useful probe:
Current milestone and exact next action:
Plan and evidence locations:
Implemented work and remaining consumers:
Checks passed, failed, blocked or not run:
Authorization for pending actions and destinations:
Active jobs, external state and cleanup owners:
Parallel work scopes and integration owner:
Unresolved prerequisites and independent work:
Recovery artifacts and self-contained continuation:
```

Link raw observations to their input, source, environment, time and interpretation. Keep failures that explain a conclusion. Reference secrets by role or approved location.

Record a changed assumption and the work it affects. Preserve the original outcome unless the user actually changes it. A status question or clarification during execution usually steers the active task rather than replacing it.
