# Write an executable operating procedure

Write for an operator completing one defined task. The procedure should expose its prerequisites, actions, expected observations and recovery decisions without depending on the author or a previous conversation.

Skills: `write-docs`.

| Need | Read |
| --- | --- |
| Define the promise and appropriate detail | [Structure](structure.md) |
| Make each step usable | [Actions and observations](steps.md) |
| Choose checks and evidence | [Checks](checks.md) |
| Exercise instructions safely | [Rehearsal](rehearsal.md) |
| Keep corrections in every consumer | [Maintenance](maintenance.md) |
| Select current sources and retain their scope | [Sources](sources.md) |

The [documentation reference](../../../references/docs.md) owns general documentation practice. Use the target repository's exact commands and state contract. Examples in this handbook are design prompts until bound to that source.
